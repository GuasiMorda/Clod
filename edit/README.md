# STATE RP — Dark Phonk car edit

Вертикальный эдит 1080×1920, 60 fps, ровно 20,000 с, монтаж синхронизирован с `music/track.mp3`.

## Рендер

```bash
pip install opencv-python-headless numpy pillow   # + ffmpeg в системе
python3 edit.py                         # -> out/edit_staterp.mp4
python3 edit.py --stills 3.1,10.2,17.4  # превью кадров -> out/stills/
```

## Как устроено

- `SONG_START` — секунда трека, с которой начинается ролик. Сейчас 4,20: дроп трека ложится ровно на 3,0 с эдита.
- `music/beats.npy` — удары трека, найдены автоматически (136 BPM). Все склейки в `TIMELINE` задаются номером удара относительно дропа: `b0=7, b1=9` — шот с 7-го по 9-й удар. `STOP` и `HIT` — стоп-пауза трека и возврат баса.
- `TIMELINE` — список шотов. У каждого шота есть:
  - `cam` — движение камеры по кадру: `(cx, cy, zoom, rot)` в начале и в конце;
  - `car` и `move` — анимация машины: `slide_in`, `drift_in`, `launch`, `driveby`, `drift_osc`, `away`, `creep`;
  - `ramp` — speed ramp: `fsf` (быстро-медленно-быстро), `slow` (slow-mo), `eo`, `eio`;
  - `trans` — переход на входе в шот: `flash`, `zoom`, `whip`, `cut`;
  - `hit`, `rgb`, `flip`, `spray`, `dolly`, `fade`, `blur` — сила удара, RGB split, зеркало, снег из-под колёс, рывок вперёд, затемнение, motion blur.
- `engine.py` — слои машин, свет фар, отражения, снег, свечение.
- Глобально, на каждый кадр: зум и тряска по ударам и по басу, флэши, RGB split, свечение, цветокоррекция «dark phonk», плёночное зерно, виньетка.

## Как подставить настоящие записи из BeamNG.drive

1. Положи клипы в `clips/` (1080p и выше, 60 fps).
2. Замени нужный шот в `TIMELINE` на клип:
   ```python
   dict(kind="clip", file="drift_01.mp4", **{"in": 12.4}, speed=1.0, ramp="fsf", zoom=1.1, b0=7, b1=9, trans="flash", hit=0.6)
   ```
   `in` — секунда начала в клипе, `speed` — скорость, `zoom` — дополнительное приближение. Клип сам обрезается под 9:16.
3. Запусти `python3 edit.py`. Тайминги, переходы и эффекты останутся привязаны к ударам.

## Исходники кадров

Сейчас шоты собраны из машин дизайн-референса STATE RP: BMW E38, Mercedes-AMG, Dodge Charger, ВАЗ, BMW F10. Машины вырезаны в отдельные слои (`cars/`), фоны очищены (`plates/`). Текста в кадре нет: надписи референса и неоновая вывеска удалены.
